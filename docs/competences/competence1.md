# Compétence 1 : Réaliser un développement d’application

## Description

Développer une solution informatique consiste à transformer un besoin exprimé en une application fonctionnelle, testée, maintenable et adaptée à l’utilisateur.

Cette compétence implique :
- l’élaboration et l’implémentation des spécifications techniques,
- le respect des exigences fonctionnelles et non fonctionnelles,
- la production de code structuré, lisible, réutilisable et documenté,
- l’intégration dans un environnement de production si nécessaire.

## Projets associés

### [Stage chez Covéa](/projets/stagecovea/mission1)
- Développement et correction de jobs Talend pour la gestion des dates (UTC/CET).
- Intégration dans des pipelines Jenkins et tests dans différents environnements.

### [Projet tutoré - LogBase](/projets/projetlogbase)
- Conception d'une application d’analyse de logs SQL en Python avec le framework Kivy.
- Développement du parser, du filtrage par date et de l'affichage graphique.

### [SAE](/projets/saecapteurs)
- Conception d’une interface React connectée à une API FastAPI pour afficher des données environnementales en temps réel.
