# Compétence 3 : Administrer des systèmes informatiques communicants complexes

## Description

Administrer un système communicant complexe consiste à installer, configurer, maintenir et sécuriser une infrastructure informatique répartie.  
Cette compétence implique :
- la gestion d’environnements multi-utilisateurs,
- l’intégration de services communicants (API, réseau),
- la supervision de systèmes répartis sur plusieurs environnements (dev, test, production),
- l'application des bonnes pratiques de sécurité et de continuité de service.

## Projets associés

### [Stage chez Covéa](/projets/stagecovea/entreprise)
- Travail sur un écosystème Big Data réparti entre plusieurs environnements.
- Utilisation de Jenkins pour déployer les traitements dans différents contextes : développement, test, performance.
- Résolution d’erreurs dans les jobs Talend, via l’analyse de logs et l’investigation système.

### [SAE](/projets/saecapteurs)
- Mise en œuvre d’une application full-stack communicante avec une API FastAPI reliée à un front-end React.
- Gestion des échanges entre services, configuration du serveur et appel des routes API.

## Bilan

J’ai appris à comprendre l’organisation d’un système réparti, à manipuler des outils d’industrialisation comme Jenkins, et à diagnostiquer des erreurs liées au contexte d’exécution.
